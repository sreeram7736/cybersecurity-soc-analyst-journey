# DNS Traffic Analysis Using Wireshark

## Objective
Understand how DNS requests and responses work.

## Tools Used
- Wireshark
- Web Browser

## Lab Environment
Personal computer and authorized network.

## Procedure
1. Open Wireshark.
2. Select the active network interface.
3. Start packet capture.
4. Visit a website.
5. Apply the DNS display filter.
6. Observe DNS requests and responses.
